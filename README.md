# 🐾 Taner Talas | TinCat Project

## 🇬🇧 English

TinCat is a fictional landing page inspired by modern dating apps, reimagined for cat lovers.
This project was built as a frontend-focused portfolio project to practice layout, animations, performance optimization, and UI/UX details.

The goal of TinCat is not functionality, but polished presentation - smooth interactions, responsive design, and thoughtful micro-animations.

🛠️ Built with:
- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5
- GSAP (via CDN)
- Lenis (smooth scrolling)

✨ Features:
- Responsive Layout built with Bootstrap
- Smooth animations using CSS
- Smooth Scroll with Lenis
- Infinite Brand Loop Animation with GSAP
- Performance-aware design (optimized for CLS, LCP, INP)

🔗 **Live Demo**: [tanertalas.github.io/TinCat](https://tanertalas.github.io/TinCat)

## 🇹🇷 Türkçe

TinCat, modern flört uygulamalarından ilham alan, kedi severler için yeniden hayal edilmiş kurgusal bir landing page projesidir.
Bu proje; yerleşim (layout), animasyonlar, performans optimizasyonu ve UI/UX detaylarını geliştirmek amacıyla hazırlanmış, frontend odaklı bir portföy çalışmasıdır.

TinCat’in amacı işlevsellik değil, pürüzsüz ve özenli bir sunumdur — akıcı etkileşimler, responsive tasarım ve düşünülmüş mikro animasyonlar ön plandadır.

🛠️ Kullanılan Teknolojiler:
- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5
- GSAP (CDN üzerinden)
- Lenis (akıcı kaydırma / smooth scrolling)

✨ Özellikler:
- Bootstrap ile oluşturulmuş responsive layout
- CSS ile hazırlanmış akıcı animasyonlar
- Lenis ile smooth scroll deneyimi
- GSAP ile sonsuz marka döngüsü animasyonu
- Performans odaklı tasarım (CLS, LCP, INP metrikleri gözetilerek)
